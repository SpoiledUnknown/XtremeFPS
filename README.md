## Description

An advance yet easy to use and modify First Person Prespective based character controller which intends to reduce developement time and provide realistic experience to player using procedural animation + support for pre-baked animations.

---

# ⚠️ Project Status

> **This project has been officially deprecated and archived.**

XtremeFPS Controller has been completely removed from the Unity Asset Store and is no longer actively maintained or supported.

This repository is now preserved as a **public archive** for educational purposes, reference, and community use.

While I currently have no plans to continue development, I may choose to completely redesign and remake the asset in the future if time permits. However, there is no active roadmap or timeline for such a revival.
